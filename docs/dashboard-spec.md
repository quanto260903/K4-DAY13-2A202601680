# Dashboard Specification

Runtime source: `data/logs.jsonl`

Dashboard contract source: `config/dashboard.yaml`

Tooling: the local runtime dashboard generated by `scripts/generate_dashboard.py`. Langfuse remains the trace and prompt-versioning surface.

Default time range: 60 minutes

Refresh interval: 30 seconds

## Panels

| # | Panel | Metric fields | Unit | Visualization | Threshold / SLO line |
|---|---|---|---|---|---|
| 1 | Latency percentiles | `response_sent.latency_ms` | `ms` | P50/P95/P99 stat panel | P95 `<= 3000 ms` |
| 2 | Request traffic | `request_received` | `requests_per_minute` | Request count and rate | Rate `>= 1 request/min` during load test |
| 3 | Error rate and breakdown | `request_failed.error_type` | `percent` | Percentage stat plus breakdown | Error rate `<= 2%` |
| 4 | Cost over time | `response_sent.cost_usd` | `usd` | Minute buckets plus total | Total cost `<= 2.5 USD` |
| 5 | Input and output tokens | `response_sent.tokens_in`, `tokens_out` | `tokens` | Two totals | Total token budget `<= 50000` |
| 6 | Quality proxy | `response_sent.quality_score` | `score_0_to_1` | Average score gauge | Average quality `>= 0.75` |

## Runtime Check

Generate the dashboard from the current JSONL log:

```bash
python scripts/generate_dashboard.py
```

Open the generated runtime view:

```powershell
start submission/evidence/dashboard.html
```

## Contract Check

Run the validator before capturing evidence:

```bash
python scripts/validate_dashboard.py
```

Expected output:

```text
HOP LE: 6/6 panel co trong dashboard contract.
```

## Evidence Checklist

- Screenshot or exported view includes all 6 panels.
- Screenshot shows the 60 minute time range.
- Panel titles and units are visible.
- Threshold or SLO line is visible for latency, errors, cost, tokens, and quality.
- Evidence file is saved under `submission/evidence/`.
